# Alyx's Studio

- 网站：https://alyxsstudio.com
- 后台：https://alyxsstudio.com/admin
- 托管：GitHub Pages。每次在后台点保存，GitHub 会自动发布，大约 1 分钟后生效。

## 栏目

| 栏目 | 放什么 | 在后台哪里改 |
|---|---|---|
| Daily | 碎碎念、感悟、图片、语音、转载、截图。网站上有日历，有更新的那天显示缩略图 | Daily 日常 |
| Serial（原 Ongoing / Novel） | 每天在长的合集：连载小说、图片词典、图片连载……会按设定自动排序，可以打包下载 | 先在「Ongoing 合集设置」建合集，再在「Ongoing 每日更新」里往合集加条目 |
| Thesis（只有你看得到） | 论文写作间：像连载一样按章写，再把全部章节合成一篇去翻译 → 出处 → 排版。访客的菜单里没有这一栏 | 网页上直接用（`/write/`） |
| Watch | 视频：贴 YouTube、TikTok、Instagram、B站、抖音、Vimeo 的链接，网站上直接显示视频；也可以上传短视频文件 | 网页上点 **+**，或后台「Watch · Listen 视频和音乐」 |
| Listen | 音乐和播客：贴 Spotify、Apple Music、Apple Podcasts、SoundCloud、Bandcamp、网易云的链接，显示播放器；自己的歌可以直接上传，有 Play all | 同上 |
| Library（原 Books） | 书：封面、简介、购买链接；可以上传 PDF（最大 95MB），设置成访客能读/下载，或只有你能看。点封面进入这本书的单独页面 | 网页上点书的 Edit |
| Gallery（Visual） | 壁纸、头像、封面系列，可以设置成访客能下载。另有只给你看的 **Inspiration 灵感板** | Visual 图片系列 |
| Design | 草图、构思图 | Design 草图·构思 |
| Store | 衣服、帽子、包、挂件……附购买链接 | Books · Store · Traces → Store |
| Traces | 作品去过的地方：发表、展出、对谈、合作、协会、报道 | Books · Store · Traces → Traces |
| Follow | 所有平台的链接，同时显示在每页底部 | Site 网站设置 → Follow |

- **改栏目名字或菜单顺序**：只在「Site 网站设置 → 栏目名称和菜单」里改。菜单、首页和页面标题会一起变。
- **首页显示什么、按什么顺序**：在「Site 网站设置 → 首页 · 联系方式 → 首页模块」里调整。
- **字体、颜色、字号、每行几张图**：在「Site 网站设置 → Look」里改。

## 在网页上直接编辑（不用进后台）
1. 在你的设备上打开一次 `alyxsstudio.com/?me`，进入"我"的模式（Owner）。
2. 第一次保存前，在同一个浏览器里打开 `/admin` 登录一次。网页编辑用的是同一个登录。

进入后，网站上能看到的几乎所有东西都可以直接改：
- **带虚线下划线的字**：点一下直接改，比如栏目名（Ongoing、Traces……）、页面介绍、首页小标题、系列名、合集名、底部邮箱。改完按回车或点别处。
  - 这类改动会先存在你的设备上，左下角出现 **"N changes · Publish"**，点 **Publish** 才发布到网站；点 **Undo** 撤销。
- **首页**：每个模块上方有 ↑ ↓ 移动、**Edit** 设置、× 删除；模块之间有 **+ Add a block here**，可以加文字、大图、日常、视频等模块。
- **各栏目**：
  - Store、Books、Traces、Follow：每项下面有 **Edit** 和 ← → 移动，顶部有 **+ New**。
  - 分类：Store、Books 的分类旁边有 ✎，可以改名；新分类在添加或编辑物品时直接输入。
  - Visual：每张图有 Edit 和 ← →，系列有 Series settings。
  - Ongoing：合集有 Collection settings。
  - Daily：日历上点空白的一天就是在那天发新日常；点已有日常的文字就能修改。
- **左下角 ✎ Owner**：
  - **Menu & page names**：改菜单顺序和栏目名。
  - **Name, logo, email**：网站名、logo、邮箱、顶部通知。
  - **Fonts, colours, sizes**：字体、颜色、字号、中文字体和中文大小，改的时候页面马上变。
  - 切换"你看到的语言"，下载全站备份，退出 Owner 模式。
- **草稿自动保存**：所有表单（日常、章节、物品、设置……）边写边自动存在这台设备上，关掉或刷新再打开会接着写，保存成功后草稿自动清掉。

保存后，网站大约 1 分钟后更新。

## Watch 和 Listen：贴链接就显示
- 在 Watch 或 Listen 页面点右下角 **+**：
  - **Paste a link**：粘贴作品页面的链接，下面马上出现预览。标题可以不填。
  - **Upload a file**：上传自己的歌、录音或短视频（95MB 以内），可以加封面。
- 发布时网站会自动去平台抓标题和封面，封面会存一份在网站里，平台以后删图也不影响。
- 视频滑到屏幕中间会自动静音播放，点一下就是有声音的正常播放。不想自动播放：后台「首页 · 联系方式」里关掉"视频滑到屏幕中间时自动静音播放"。
- 视频自动放 Watch，音乐和播客自动放 Listen；想换位置，在编辑里改"Show it in"。
- 自己上传的歌会排成歌单，点 **Play all** 连着播，底部有播放条。
- Daily 的"转载 / 链接"里贴视频或音乐链接，也会直接显示成播放器。
- 小红书、微博、X 这些不让别的网站嵌入播放，会显示成带封面的卡片，点了去原页面看。
- 抓取情况记在 `data/embeds.json`，想改某个标题可以直接改这里。

## 中文写，英文显示（先确认再公开）
- 你用中文写，后台保存中文原文。
- **访客只看到你确认过的英文**；还没确认的部分，访客看到的是中文。（想改回自动显示机器翻译：后台 Site → 首页 · 联系方式 →"访客看到的英文"。）
- **翻译台**：Owner 模式下，凡是中文写的内容旁边都有 **English** 按钮（确认过的显示 **English ✓**）。点开是左右对照：
  - 左边中文，右边写英文，一段对一段。
  - 每段有 **DeepL ↗**：在 DeepL 网页里打开这一段，复制回来再改。
  - **Use machine draft / Fill empty with drafts**：把自动生成的英文草稿放进来，作为修改的起点。
  - **Tidy**：改成英文标点，《书名》变成*斜体*。
  - 写到一半会自动存成私密草稿，换设备也在。改好点 **Approve**，约 1 分钟后访客就能看到。
- **✎ Owner → English versions**：列出所有中文内容，哪些已经有英文、哪些还没有。
- 菜单名、页面介绍这类短文字：直接点字改成你想给访客看的英文名字就行（比如你现在的 Feed、Draft）。
- 想要更好的英文草稿，可以在 GitHub 存 `GEMINI_API_KEY`、`DEEPL_API_KEY` 或 `ANTHROPIC_API_KEY`（Settings → Secrets and variables → Actions）。没有钥匙就用免费的 MyMemory，草稿比较生硬。

## 🔒 锁：暂时不公开
- Owner 模式左下角有 **🔓 Public / 🔒 Private** 按钮。
- 锁上后约 1 分钟，访客打开任何页面都只看到 "Private for now"，搜索引擎也不会收录。你自己（Owner 模式）照常看、照常改。
- 注意：网站的文件放在公开的 GitHub 仓库里，锁只是挡住访客的页面，不是加密。真正私密的东西（草稿、私人日历）都放在私密仓库 `studio-drafts` 里。

## 首页：更新日历
- 首页现在只有一个 **Updates** 日历：每天哪些栏目有更新，用栏目首字母圈标出来（F = Feed，D = Draft……），点一天看当天更新了什么。
- 其他模块随时可以用 **+ Add a block** 加回来。

## Feed：只有你能看的私人日历
- Owner 模式打开 Feed，日历右边多了 **My day · only you**：
  - 喝水（杯）、上厕所、💩 次数，点 + / −。
  - 心情、🩸 月经（无 / 点滴 / 少 / 中 / 多），会算出下次大概哪天、晚了几天、平均周期。
  - 吃了什么：输入食物（常见的中英文食物都有，比如"米饭""鸡胸肉""奶茶"），选份量，自动算热量、蛋白质、碳水、膳食纤维、蔬菜份数，和每日目标对比"够不够"。列表里没有的，填一次数字就会记住；在设置里填 Gemini 钥匙，还可以让 AI 估算。
  - 饮料：一键添加咖啡、奶茶、可乐……
  - 花了多少钱：金额 + 分类（Shopping、Food……可以自己改），日历上方显示本月总额和各类花费。
  - 随手记。
  - 电脑时间（装了 Mac 小程序后显示，见下）。
- 日历格子上会出现小图标：心情、🩸、🍽、💰、✎。
- 这些全部存在你的**私密仓库** `studio-drafts` 的 `journal/` 里，**不会出现在网站上**，访客的 Feed 只有公开的日常。
- 目标数值（热量、蛋白质、喝水……）、货币符号、花费分类：私人日历底部 **Targets, currency, AI key…**。

## 电脑时间（Mac 小程序）
记录每天几点到几点在用电脑、用的是哪个软件或网站，自动分成"工作"、"休息娱乐"、"其他"，离开电脑 5 分钟以上算休息。每 10 分钟同步一次到私人日历。
1. 先在网站上写过一次草稿（这样私密仓库 `studio-drafts` 已经建好）。
2. 在 GitHub 新建一个钥匙：github.com/settings/personal-access-tokens/new
   - Repository access 选 **Only select repositories → studio-drafts**
   - Permissions → Repository permissions → **Contents: Read and write**
   - 生成后复制。
3. 打开 Mac 的"终端"，粘贴这一行，回车，按提示粘贴钥匙：
   `curl -fsSL https://raw.githubusercontent.com/alyxsstudio/alyxsstudio/main/tools/mac-activity/install.sh | bash`
4. 第一次 Mac 可能会问"osascript 想控制 Safari / Chrome"：允许的话能按网站区分工作和娱乐（比如 YouTube 算休息、Google Docs 算工作），不允许也能用。
- 哪些软件、网站算工作或休息：改 `~/Library/Application Support/AlyxActivity/apps.json`。
- 卸载：`curl -fsSL https://raw.githubusercontent.com/alyxsstudio/alyxsstudio/main/tools/mac-activity/uninstall.sh | bash`

## Thesis 论文写作间（只有你能看）
菜单里的 **Thesis**（网址 `/write/`）。访客看不到这一栏。每篇论文按章写，后三步把所有章节合成一篇。

**保存**：每一个改动都马上存在这个浏览器里（刷新、关掉都不会丢），几秒后再存进私密仓库 `studio-drafts/papers/`，换设备也能打开。右上角显示状态：**✓ Saved** = 已经存进私密仓库；**Saved on this device** = 已经存在这台设备上，私密仓库暂时连不上（把鼠标放上去能看到原因，一般是需要在 `/admin` 重新登录一次）。

**1 Write 写：像连载一样按章写**
- 每篇论文像 Serial 里的一部作品：分成一章一章（一个话题一章，顺序以后可以用 ↑ ↓ 调）。两章之间（和第一章前面）有一个淡淡的 **+ Insert a chapter** 按钮，可以在任何位置插入新的一章。点 **+ New chapter** 开新的一章，或 **Add a file as a chapter**（也可以直接拖进 .docx / .pdf / .md / .txt），每个文件成为一章。
- 打开论文就能看到**每一章的正文全文**，不只是章节名；上方是章节目录，点一下跳到那一章。章节名可以留空。
- 点任何一章的正文进入写作页，光标就在你点的那个字上，那一段停在屏幕上原来的位置；点 **Write** 则从章末开始。写作页边写边自动保存；**← Previous / Next →** 换章。斜体 = 作品名；**H** = 章内小标题；Shift+Enter 让诗句分行留在同一段。
- **新加进来的材料**：在章里粘贴的整段内容（新发现、想保留的原文引文、笔记）左边有一条黄线，标明"还没融进去"。
- **✦ Gemini writes it in（让 Gemini 直接写进去）**：在写作页右上角打开。Gemini 把这一章重新写成完整的一篇，把新加的段落融进去：放到论证里合适的位置、写好过渡、交代引文（谁写的、哪部作品、何时、说明了什么）、解释人名和术语、讲清背后的机制。规则是每个事实、日期、数字、引文都保留，不概括、不缩短（写短了会自动再写一次），引文保持原文和分行，不编造史料；你写给自己的笔记不放进正文，单独列在旁边。
  - 写完直接替换这一章，旁边显示字数对比，并列出原文里有、Gemini 版本里没有的年份、外文词和书名，方便你核对。
  - 你的原版一直保留：**↩ Back to my version** 一键换回（再点一次又换成 Gemini 的），**See my version** 可以对照着看。
  - 可以在框里给这一章写一句要求（比如"开头用 1794 年沙龙的画面"）。
  - 没有 Gemini 钥匙时：点 **Copy for Gemini**，贴到 gemini.google.com，把它写好的章节贴回 **Paste Gemini's answer**，一样放进这一章。
- **Thesis & style → About this article**：写下这篇文章在论证什么、人物和术语、新发现、写作原则、要核实的矛盾。Gemini 写之前先读它。
- 原来在 Serial 里写的 **Lucas** 已经搬到这里（连同没发表的草稿），并从公开网站上删掉了。

**2–4 步把所有章节合成一篇**：翻译、出处和检查、MLA 排版都是整篇文章（章节按顺序接起来）。在第 3、4 步里改的字也会改回它所在的章。有标题的章节在合成的文章里是小标题；不想要的话，Format → More → **Leave chapter titles out of the article**。

**2 Translate 翻译（DeepL）**：每段旁边有 **DeepL ↗**；也可以把全文复制去 DeepL 再一次贴回来，按段落对齐。葡萄牙语、英语引文和外文书名不会被翻译。英文直接在右边改，自动保存。

**3 Sources & checks 出处和检查**：还是你的文档，按你的顺序，可以直接改。标记只在屏幕上，复制出来是干净的文字：
- **红色虚线** = 需要引用（引文、"某某认为"、具体的事实和年代没有出处）。点一下：Google AI Mode / Scholar / PDF 搜索，或 **Find the source with Gemini**（联网找出处）→ **Insert the citation**：括号引用插进句子，条目自动加进 Works Cited。
- **橙色** = 和已发表的文字很接近。点 **Compare with published texts**，Gemini 用谷歌搜索逐段比对，标出接近的句子和来源链接；点句子可以 **Say it in my own words**。（这是谷歌搜索比对，不是 Turnitin 那样的完整查重数据库。）
- **紫色虚线** = 读起来像 AI 写的（套话、空泛的大词、过于整齐的句式）。常见套话会自动标出；点 **Look for AI-sounding writing** 让 Gemini 细读，每句给一个用你自己口吻的改写，点 **Use this** 替换。说明：没有任何工具能百分之百判断是不是 AI 写的，这里标的是读者和检测工具会注意到的特征。
- 不需要处理的点 **Ignore**。有英文译文时可以切换中文 / English。

**4 Format 排版（MLA 9）**：显示成一张会打印出来的纸，直接在上面改：
- 顶部四行（名字、老师、课程、日期）直接点进去填；右上角自动显示姓 + 页码；标题居中；正文首行缩进、双倍行距。
- Works Cited 在文末，一行一条，点别处就自动按 A–Z 排好、悬挂缩进；和文章最后的 Works Cited、第 3 步插入的引用是同一份。
- MLA 的小错误用黄色标出，点一下 **Fix**，或 **Fix all**。**More** 里有 Gemini 检查引用、葡萄牙语拼写检查（葡萄牙 / 巴西）。
- **Download .docx** 下载排好版的 Word 文件。

**Thesis & style**（右上角）：论点、关键词、读者、你喜欢的文笔（Gemini 会模仿）、Gemini 钥匙和模型（Pro 文笔最好；免费钥匙用不了 Pro 时自动改用 Flash）。

## Gallery 灵感板 Inspiration（只有你能看）
Gallery 页面上方 **Inspiration · only you**（网址 `/visual/#inspiration`）。
- 在页面任何地方粘贴（⌘V）：截图、复制的图片、图片链接、网页链接（Pinterest、Instagram、小红书、商店、文章……会取网页的预览图），也可以拖进来或 **Choose pictures**。
- 每张图马上存成 JPG，放进私密仓库 `studio-drafts/inspiration/`，不会出现在网站上；原链接也记下来。
- 自动分类：有 Gemini 钥匙时，Gemini 看图起主题名（尽量用已有的主题）和标签；同时按颜色、按来源自动归类。上方切换 **By theme / By colour / By source / Newest**。没有钥匙的图在 "Not sorted yet"，有钥匙后点 **Sort with Gemini**，或者自己填主题。
- 点图片：看大图、改主题/标题/标签、**Download JPG**、删除。每组右边 **Download all (JPG)** 打包成 zip。

## 引用卡片
在任何文章或章节里选中一段文字，会出现 **Quote card** 按钮，点一下生成一张 Story 尺寸的引用图。手机上会直接调出分享面板。

## 打包下载
- **合集**（Ongoing）可以导出 PDF、EPUB 或 ZIP：
  - EPUB 可以直接用 Kindle 的 "Send to Kindle" 发送，也可以上传到 Apple Books。
  - ZIP 里是原图和每一条的文字。
- 每个合集和每个 Visual 系列都可以单独设置下载权限：**只有我**，或者**所有访客**。
- **"只有我"是怎么判断的**：在自己的电脑或手机上打开一次 `alyxsstudio.com/?me`，那台设备就进入"我"的模式，能看到所有下载按钮。页面底部还有 **Download everything**，可以把整个网站（文字、图片、音频）打包成一个 ZIP 备份。
  - 退出这个模式：打开 `alyxsstudio.com/?me=0`。
  - 注意：这只是把按钮藏起来，不是加密。网站上的内容本身是公开的。

## 小提示
- 图片默认**完整显示，不裁剪**（A4 页面、书封、竖长图都完整）。想要整齐的统一形状：✎ Owner → Fonts, colours, sizes → Pictures。
- 上传的图片会自动转成 webp，并缩小到长边 2880px 以内，网站不会越来越慢。
- 语音和音频建议每个 30MB 以内。
- 想先写好、暂时不公开，就勾选"先不公开"。
- 旧的网址（/shop、/art、/serial……）会自动跳转到新栏目。

## 技术说明
- `content/`：Daily、Ongoing、Visual、Design 的内容，一条一个文件。
- `data/`：其余设置和列表。
- `scripts/build.mjs`：发布时把 `content/` 整理成网站用的数据。
- `.github/workflows/pages.yml`：自动发布到 GitHub Pages。
